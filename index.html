Folio

Personal project · formerly CourseVault

A desktop application that organizes course materials and connects AI answers to the files they came from.

I initiated the project and continue to develop it through AI-assisted implementation, review, and testing. A public macOS build is available for Apple Silicon Macs; source code remains private.

Electron · Angular · Python · SQLite

Download for Mac (opens in a new tab)

Project notes +

The problem

Course information is spread across Canvas, instructor websites, and local files. Repeated uploads make it harder to keep questions connected to the right materials.

My role

I initiated the project and continue to define its workflows, review implementation, and iterate through AI-assisted development and hands-on use.

How it works

Read-only material discovery feeds a local workspace. Keyword and multilingual semantic retrieval support course-scoped questions; citations open the original sources for checking.

Current stage

Folio was previously called CourseVault. A public build is available for Apple Silicon Macs running macOS 14 or later. Development continues, and source code remains private.

QuizReady

UNC COMP 423

A tool for reviewing graded PDFs and creating practice quizzes, built as my software engineering final project.

I designed and implemented the QuizReady features within the existing LearnWithAI platform. PDF processing runs in background jobs, with question-level feedback displayed in the web interface.

Angular · FastAPI · PostgreSQL · Azure OpenAI

Project notes +

The problem

Scores, handwritten responses, and grading rubrics are spread across a graded PDF. Students need a clearer way to review individual questions and identify what to revisit.

My role

I designed and implemented the QuizReady features as my COMP 423 final project, integrating them into the existing LearnWithAI course platform.

How it works

A FastAPI service accepts uploads and queues background processing with Dramatiq and RabbitMQ. PDF and vision processing produce feedback; the Angular interface tracks the job and displays results.

Beyond PDF review

Instructors can create and publish practice quizzes. Students can submit responses and receive immediate scoring for multiple-choice questions.

Video evaluation

I assisted a PhD student with early work on video evaluation. I prepared a server environment, tried VBench, investigated existing methods, and ran RTMO to export human pose keypoints.

The question was how to evaluate basketball motion when a general video-quality score did not match what we saw in a clip.

Read about the work +

Some short clips received high general-purpose quality scores despite visibly unsatisfactory results. I investigated existing approaches that could better capture basketball motion and body consistency.

My contribution focused on method research, preliminary testing, and pose-data export. The work explored evaluation approaches rather than establishing a validated motion-error detector.

Car–trailer control

Boshen Yang*, Tianyi Zhang* · *Equal contribution

With Tianyi Zhang and guidance from Changliu Liu, I studied tracking and obstacle avoidance in a simplified car–trailer model. Our joint work used MATLAB simulation, a genetic algorithm, and SQP parameter optimization.

Publication & scope +

The paper reports results under idealized numerical simulation conditions. It does not establish real-vehicle validation or a general safety guarantee.

Palworld Guide

Open-source Agent Skill · Beta

Tools for recurring gameplay questions.

An open-source Agent Skill for Palworld guidance, with tools for breeding routes, material deficits, map marking, and read-only checks of server settings.

I built it around recurring gameplay questions. Local Python tools handle planning and calculations; the host assistant can research public sources and continue saved tasks when more evidence is needed.
